# 智遊日誌 WanderWise · 智慧一日遊行程規劃器

專為旅人打造的智慧一日遊行程規劃網頁程式。只需輸入目的地所在地（例如：台北、台南、東京、京都、曼谷、巴黎...），系統便會即時呈現：

1. **🏛️ TOP 5 最熱門觀光景點**：評分、停留時長、開放時間、必玩亮點、建議視角與 Google 地圖一鍵導航。
2. **🍽️ TOP 5 最好吃口碑名店**：美食分類、消費價位、必點招牌名菜、用餐氛圍與 Google 地圖一鍵導航。
3. **🕒 09:00 - 19:00 黃金一日行程時間軸**：精確安排晨間出發、上午代表景點、午間饗宴、午後文化探索、下午茶甜點微歇、日落景觀勝地、到晚霞盛宴的流暢節奏。
4. **🗺️ 互動定位地圖 (Leaflet.js + OpenStreetMap)**：標記五大景點（藍色 1-5）與五大餐廳（橘色 1-5），直觀掌握景點分佈。
5. **📋 一鍵匯出與分享**：支援「一鍵複製完整行程文字」與「友善列印 / 存為 PDF」。

---

## 🚀 快速啟動方式

本程式為純前端單頁應用程式 (Single Page Application)，無需安裝複雜環境，開箱即用：

- **方式一（最簡單）：**
  - 直接雙擊執行專案資料夾內的 `點我開啟網頁.bat`，或在檔案總管中對 `index.html` 按兩下，即可在 Chrome / Edge / Firefox 中開啟！
  
- **方式二（本地伺服器）：**
  - 雙擊執行 `啟動本地伺服器.bat`，系統會自動在 `http://localhost:8080` 啟動本地 Python HTTP 伺服器並自動開啟瀏覽器。

---

## 🌟 核心特色

- **零門檻開箱即用**：內建台北、台南、東京、京都、曼谷等全球熱門旅遊城市的深度高精度資料庫。
- **全方位動態支援**：若輸入非預設城市（如：宜蘭、花蓮、首爾、新加坡、紐約...），內建智慧地理定位與合成引擎會自動抓取經緯度並生成客製化一日行程。
- **支援 Gemini AI 自由擴充 (選填)**：點擊右上角「AI 設定」，可填入個人的 Google Gemini API Key，即可啟用更具深度、無拘無束的即時 AI 生成旅遊導覽。
- **響應式現代設計**：適配電腦、平板與手機螢幕，支援列印排版優化。
